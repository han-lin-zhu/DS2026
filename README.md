# Data Structures and Algorithms

本仓库用于存放 **数据结构与算法** 课程的作业与学习代码。

课程使用 **C++**，并要求在学习过程中尽量自行实现所需的数据结构与算法，而不是直接使用 C++ STL 中已经提供的实现。

因此，后续会随着课程进度逐步编写和完善自己的基础数据结构与算法组件。
